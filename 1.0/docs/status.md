# Wodby platform status

Current platform incidents and maintenance notices are published at
[status.wodby.com](https://status.wodby.com/).

Applications normally continue serving traffic from their connected servers
when the Wodby control plane is temporarily unavailable. Operations that depend
on the control plane—such as dashboard changes, deployments, scheduled backups,
notifications, and task-result processing—can be delayed until service is
restored.

If an incident is not listed, collect the affected organization, application,
instance or server UUID, task ID, and the time the problem began, then contact
[Wodby support](support.md). Do not include passwords, private keys, protected
environment values, or raw deployment manifests in a support request.
