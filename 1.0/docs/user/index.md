# User

Manage your personal account from the **Account** menu in the Wodby dashboard.

- [Account](account.md): organization membership and account deletion.
- [Security](security.md): two-factor authentication, recovery codes, and sensitive actions.
- [API keys](api-keys.md): create and revoke credentials for integrations and CI pipelines.
- [SSH keys](ssh-keys.md): add public keys for access to SSH containers.

Organization membership and resource permissions are described under [Organization](../org.md).
