Introduction

This is the Wodby 1 API reference, covering the public REST API at https://api.wodby.com/api/v3. For Wodby 2, see the Wodby 2 API reference.

The Wodby 1 API is organized around REST. Our API has predictable, resource-oriented URLs, and uses HTTP response codes to indicate API errors. We use built-in HTTP features, like HTTP authentication and HTTP verbs, which are understood by off-the-shelf HTTP clients.

JSON is returned by all API responses, including errors.

Authentication

Authenticate your account by including your secret key in API requests. Create an organization-scoped API key under Account > API Keys in the Dashboard. New keys can access only their organization and inherit the permissions of their owner. The secret is shown once; keys may expire or be revoked. Existing legacy global keys remain compatible. Your API keys carry many privileges, so be sure to keep them secure! Do not share your secret API keys in publicly accessible areas such as GitHub, client-side code, and so forth.

All API requests must be made over HTTPS. Calls made over plain HTTP will fail. API requests without authentication will also fail.

Example of authenticated request:

curl https://api.wodby.com/api/v3/user -H 'X-API-KEY: YOUR_API_KEY'
