# Development

Use the Wodby 1 API, SDKs, and CLI to automate application management and deployments.

## API keys

Create an [organization-scoped API key](../user/api-keys.md) and store its secret securely before using it in an integration or CI pipeline.

## Wodby API

See the [API and SDKs](api.md) for API v3 references, supported SDKs, and API v2 compatibility.

### Version 3

Use the [API v3 reference and SDKs](api.md#version-3) for new integrations.

### Version 2 (deprecated)

See [API v2 compatibility](api.md#version-2-deprecated) for existing integrations.

## Wodby CLI

Use the [CLI](cli.md) for command-line automation and [CI/CD](../cicd/index.md).

## Local development

Use [Docker4X](../docker4x.md) to run a local environment based on Wodby's stacks.
