# Cluster

Wodby 1 currently supports only single-node setups. Each connected server runs its own infrastructure, and an application instance runs on one server.

You can connect multiple servers and deploy different instances to them, but those servers do not form a shared, scalable cluster in Wodby 1.

## Scalable clusters with Wodby 2

For a scalable, multi-node cluster, we recommend **Wodby 2**. Its [managed Kubernetes clusters](https://wodby.com/docs/2.0/clusters/managed/) support deploying applications across a scalable cluster in your cloud account.

See [Choose a cluster option](https://wodby.com/docs/2.0/clusters/choose-platform/) to compare the available Wodby 2 deployment options.
