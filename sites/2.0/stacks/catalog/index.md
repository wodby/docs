# Catalog stack guides

Every stack in the catalog has a guide here. Guides explain what to set when creating an environment, how to sign in
or connect, and what to back up. Use them together with the stack and service configuration shown in the dashboard.

A buildable stack runs the same application built from your Git repository, with your own modules, plugins, themes
or code. Its guide covers what differs from the stack it is a variant of.

The source repository for each stack remains the authoritative reference for its current services, versions, links,
storage, and defaults. Browse all available stacks in the [Wodby stack catalog](https://wodby.com/stacks) or the
[`wodby/stacks`](https://github.com/wodby/stacks) repository.

## Shared operations

Common application operations are documented once in the shared product documentation:

- use [database details](https://wodby.com/docs/2.0/databases/) for MariaDB and PostgreSQL connection metadata
- use [published ports](https://wodby.com/docs/2.0/apps/endpoints/#publishing-ports) for external database, Redis, and other non-HTTP access
- use the [web terminal](https://wodby.com/docs/2.0/apps/web-terminal/) for interactive access to running containers
- use [imports](https://wodby.com/docs/2.0/apps/imports/), [backups](https://wodby.com/docs/2.0/apps/backups/), and [cron schedules](https://wodby.com/docs/2.0/apps/cron/) for
  application operations
- use [SMTP providers](https://wodby.com/docs/2.0/providers/smtp/) for reusable outbound mail credentials

Version histories are not duplicated here. See releases and tags in the corresponding stack and service source
repositories.
