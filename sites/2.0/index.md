# Get started

Wodby deploys and manages web applications on Kubernetes. A stack defines the services your application needs;
app environments let you deploy those services separately for development, staging, and production.

## Deploy your first application

1. Create or choose an [organization](https://wodby.com/docs/2.0/org/) and a [project](https://wodby.com/docs/2.0/projects/).
2. [Choose a cluster option](https://wodby.com/docs/2.0/clusters/choose-platform/): use your cloud account, connect your own server, or let
   Wodby create and manage the cluster.
3. [Create an application](https://wodby.com/docs/2.0/apps/#creating-new-application) from a catalog stack, configure its first
   environment, and deploy it. You can create a Wodby Cloud cluster during app creation.

For a temporary test, enable [Demo](https://wodby.com/docs/2.0/clusters/demo/) when creating a Wodby Cloud cluster. Demo clusters and their
applications are deleted automatically after 24 hours.

If the catalog does not include what you need, [create a custom stack](https://wodby.com/docs/2.0/stacks/create/). You can
[create or import services](https://wodby.com/docs/2.0/services/create/) to add to it.
