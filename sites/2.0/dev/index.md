# Development

Use these pages when you integrate external automation with Wodby.

For agent-assisted work, start with the [MCP getting started](https://wodby.com/docs/2.0/dev/mcp/). Use the [technical reference](https://wodby.com/docs/2.0/dev/mcp/reference/) when
building or troubleshooting the connection itself.

## API and SDKs

- [Wodby API](https://wodby.com/docs/2.0/dev/api/) documents the public `/v1` REST API, authentication, limits, and OpenAPI links.
- [SDKs](https://wodby.com/docs/2.0/dev/sdks/) lists official SDK packages, registry links, repositories, and compatibility with the current API reference.
- [API keys](https://wodby.com/docs/2.0/dev/api-keys/) explains how API keys are scoped, created, and used.
- [Wodby MCP](https://wodby.com/docs/2.0/dev/mcp/) connects AI assistants and coding agents to Wodby discovery, diagnostics, and operations.

## CLI

- [Wodby CLI](https://wodby.com/docs/2.0/dev/cli/) covers common CI build, push, deploy, and one-off run workflows, with links to the generated full CLI reference.
