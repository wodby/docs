# User settings

User settings contain personal account and security controls that apply to your Wodby user, not just to a single project.

Open them from your avatar menu in the dashboard.

## Sections

- [Account](https://wodby.com/docs/2.0/user/account/) for your profile and account deletion
- [Preferences](https://wodby.com/docs/2.0/user/preferences/) for dashboard appearance and your default organization
- [Emails](https://wodby.com/docs/2.0/user/emails/) for primary and secondary email addresses
- [Notifications](https://wodby.com/docs/2.0/user/notifications/) for personal email notification preferences per organization
- [Security](https://wodby.com/docs/2.0/user/security/) for password changes, two-factor authentication, and recovery codes
- [Identities](https://wodby.com/docs/2.0/user/identities/) for linked sign-in providers
- [SSH keys](https://wodby.com/docs/2.0/user/ssh-keys/) for public keys propagated to supported SSHD services
- [API keys](https://wodby.com/docs/2.0/user/api-keys/) for personal automation tokens scoped to an organization

## Organization-aware settings

Most user settings are personal. Some personal settings are also tied to an organization:

- the default organization controls which organization opens after signing in or visiting the dashboard home page
- notification preferences are personal email settings for one selected organization
- every API key is created for one specific organization
