# Application tasks

Application tasks are the same task objects described in the global [Tasks](../tasks.md) page, but filtered to one specific app environment.

You can find them at `Apps > [App] > Tasks`.

Tasks created for app sub-resources, such as builds, deployments, and cron jobs, are also associated with the app.

For more details about tasks see [Tasks](../tasks.md).
